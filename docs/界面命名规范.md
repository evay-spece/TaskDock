# TaskDock 界面命名规范

以后讨论 TaskDock 时，统一使用以下名称。

## 主界面

| 固定名称 | 指代内容 |
|---|---|
| 显示模式 | TaskDock 当前使用的任务栏或窗口矩阵布局 |
| 任务栏模式 | 屏幕底部居中的横向任务栏布局 |
| TaskDock 任务栏 | 任务栏模式下显示全部窗口卡片和工具按钮的圆角栏 |
| 窗口矩阵模式 | 屏幕右下角按 App 分列的布局 |
| 窗口矩阵 | 屏幕右下角按 App 分列显示全部窗口的浮动界面 |
| App 窗口列 | 同一个 App 的全部窗口组成的底部对齐纵向列；最先打开的窗口在最下面 |
| 窗口卡片 | 每一个独立窗口对应的圆角卡片 |
| 应用图标 | 窗口卡片最左侧的 App 图标 |
| 窗口标题 | 窗口卡片第一行文字 |
| 应用名称 | 窗口卡片第二行文字 |
| 焦点高亮 | 当前最前台窗口增加透明白底提亮，并保留底部强调色指示条；不使用强调色背景和边框 |
| 焦点指示条 | 焦点窗口卡片底部的强调色短横条 |
| 悬停高亮 | 鼠标移到窗口卡片上时出现的轻微明暗变化、阴影和放大效果 |
| 拖动目标提示 | 拖动窗口列越过另一个 App 窗口列阈值时出现的让位、描边和阴影 |
| 最小化标记 | 窗口卡片右侧圆圈中的减号，表示窗口已最小化 |
| 矩阵控制区 | 窗口矩阵最右下角的紧凑控制区域 |
| 矩阵拖动柄 | 控制菜单上方的三横线，用于移动整个窗口矩阵 |
| 矩阵控制菜单 | 右下角省略号按钮打开的功能菜单 |
| 刷新窗口 | 控制菜单中立即刷新窗口列表的菜单项 |
| 最小化全部窗口 | 控制菜单中最小化当前全部窗口的菜单项 |
| 隐藏窗口矩阵 | 控制菜单中把窗口矩阵隐藏到系统 Dock 的菜单项 |
| 退出 TaskDock | 控制菜单中关闭 TaskDock 的菜单项 |
| 权限提示区 | 未获得辅助功能权限时显示的提示内容 |
| 打开设置按钮 | 权限提示区内用于请求辅助功能权限的按钮 |

## 窗口卡片菜单

| 固定名称 | 指代内容 |
|---|---|
| 窗口卡片菜单 | 右键或长按窗口卡片后出现的操作菜单 |
| 显示全部窗口 | “显示该 App 的所有窗口”菜单项 |
| 关闭窗口 | “关闭此窗口”菜单项 |

## 设置窗口

| 固定名称 | 指代内容 |
|---|---|
| 设置窗口 | 从矩阵控制菜单或任务栏设置按钮打开的独立窗口 |
| 显示模式选择器 | “任务栏”和“窗口矩阵”两个选项组成的分段控件 |
| 主题选择器 | 浅色、深色两个选项组成的分段控件 |
| 浅色模式 | 使用浅色外观显示 TaskDock |
| 深色模式 | 使用深色外观显示 TaskDock |
| 隐藏 App 开关 | “显示隐藏 App 的窗口”复选框 |
| 黑名单区 | 设置窗口中管理不显示 App 的区域 |
| 黑名单说明 | 黑名单区标题下方的说明文字 |
| 黑名单列表 | 可加入或移出黑名单的 App 列表 |
| 黑名单勾选框 | 每个 App 左侧的复选框 |
| TaskDock 快捷键选择器 | Option、Command、Control 三个双击修饰键选项组成的分段控件 |

## 操作名称

| 固定名称 | 操作含义 |
|---|---|
| 切换窗口 | 左键单击非焦点窗口卡片，显示并置顶对应窗口 |
| 最小化焦点窗口 | 左键单击当前焦点窗口卡片，将对应窗口最小化 |
| 悬停窗口卡片 | 鼠标移动到窗口卡片上但不点击 |
| 打开窗口卡片菜单 | 右键单击或长按窗口卡片 |
| 显示 App 全部窗口 | 在窗口卡片菜单中选择“显示该 App 的所有窗口” |
| 关闭任务窗口 | 在窗口卡片菜单中选择“关闭此窗口” |
| 刷新窗口列表 | 在矩阵控制菜单中选择“刷新窗口” |
| 最小化全部窗口 | 在矩阵控制菜单中选择“最小化全部窗口” |
| 打开设置窗口 | 在矩阵控制菜单中选择“TaskDock 设置”，或点击任务栏设置按钮 |
| 切换显示模式 | 在显示模式选择器中选择“任务栏”或“窗口矩阵”，立即切换布局 |
| 调整 App 顺序 | 拖动窗口卡片跨过目标 App 窗口列靠近进入方向的四分之一位置；目标列平移 20% 让位后松手 |
| 移动窗口矩阵 | 拖动矩阵拖动柄，调整窗口矩阵的位置 |
| 隐藏窗口矩阵 | 在矩阵控制菜单中选择“隐藏窗口矩阵”；点击系统 Dock 中的 TaskDock 图标恢复 |
| 快捷隐藏或显示 TaskDock | 连续双击设置中选定的修饰键；默认为 Option |
| 退出 TaskDock | 在矩阵控制菜单中选择“退出 TaskDock” |
| 切换主题 | 在主题选择器中选择浅色或深色 |
| 显示隐藏 App | 打开隐藏 App 开关 |
| 隐藏隐藏 App | 关闭隐藏 App 开关 |
| 加入黑名单 | 勾选黑名单列表中的 App |
| 移出黑名单 | 取消勾选黑名单列表中的 App |
| 恢复最小化窗口 | 点击带最小化标记的窗口卡片 |

## 状态名称

| 固定名称 | 状态含义 |
|---|---|
| 当前焦点窗口 | 当前真正位于系统最前台的窗口 |
| 普通窗口 | 已显示、未获得焦点、未最小化的窗口 |
| 最小化窗口 | 当前处于最小化状态的窗口 |
| 隐藏 App 窗口 | 所属 App 被 macOS 隐藏的窗口 |
| 黑名单 App | 已设置为不在 TaskDock 显示的 App |
| 无标题窗口 | 没有窗口标题、因此回退显示应用名称的窗口 |

## 推荐说法示例

- “把窗口卡片的悬停高亮再深一点。”
- “焦点指示条改成 4 像素高。”
- “隐藏 App 开关默认打开。”
- “把微信加入黑名单。”
- “App 窗口列再窄一点。”
- “设置窗口宽一点，黑名单列表增加搜索框。”
