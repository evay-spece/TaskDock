# TaskDock 界面命名规范

以后讨论 TaskDock 时，统一使用以下名称。

## 主界面

| 固定名称 | 指代内容 |
|---|---|
| 显示模式 | TaskDock 当前使用的任务栏或 Dock 融合布局 |
| 任务栏模式 | 屏幕底部居中的横向任务栏布局 |
| Dock 融合模式 | 系统 Dock 两侧显示窗口任务项的布局 |
| 收藏栏 | 任务栏左侧放置常用 App 和收藏文件夹的区域 |
| 最近打开的 App | 收藏栏右侧的最近使用 App 入口 |
| 任务项 | 对应窗口或折叠 App 的卡片 |
| 窗口标题 | 任务项上显示的窗口名称 |
| 焦点高亮 | 当前最前台窗口的任务项高亮 |
| 最小化标记 | 任务项右侧表示窗口已最小化的减号 |
| 权限提示区 | 未获得辅助功能权限时显示的提示内容 |

## 设置窗口

| 固定名称 | 指代内容 |
|---|---|
| 设置窗口 | 从菜单或任务栏设置按钮打开的独立窗口 |
| 显示模式选择器 | “任务栏”和“Dock 融合”两个选项组成的菜单 |
| 任务栏模式设置 | 任务栏的尺寸、收藏与窗口显示设置 |
| 融合模式设置 | Dock 融合模式的外观和窗口显示设置 |

## 操作名称

| 固定名称 | 操作含义 |
|---|---|
| 切换窗口 | 点击非焦点任务项，显示并置顶对应窗口 |
| 最小化焦点窗口 | 点击当前焦点任务项，将对应窗口最小化 |
| 打开任务项菜单 | 右键单击或长按任务项 |
| 调整 App 顺序 | 拖动任务项，以 App 为整体调整顺序 |
| 最小化全部窗口 | 点击任务栏右侧的最小化按钮 |
| 切换显示模式 | 在显示模式选择器中选择“任务栏”或“Dock 融合” |
| 快捷隐藏或显示 TaskDock | 连续双击设置中选定的修饰键；默认为 Option |

## 状态名称

| 固定名称 | 状态含义 |
|---|---|
| 当前焦点窗口 | 当前真正位于系统最前台的窗口 |
| 普通窗口 | 已显示、未获得焦点、未最小化的窗口 |
| 最小化窗口 | 当前处于最小化状态的窗口 |
| 隐藏 App 窗口 | 所属 App 被 macOS 隐藏的窗口 |
| 黑名单 App | 已设置为不在 TaskDock 显示的 App |
