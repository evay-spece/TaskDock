# TaskDock 界面命名规范

以后讨论 TaskDock 时，统一使用以下名称。

## 主界面

| 固定名称 | 指代内容 |
|---|---|
| TaskDock 任务栏 | 屏幕底部整条圆角栏 |
| 任务项区 | 任务栏左侧显示全部窗口的区域 |
| 任务项 | 每一个独立窗口对应的圆角卡片 |
| 应用图标 | 任务项最左侧的 App 图标 |
| 窗口标题 | 任务项第一行文字 |
| 应用名称 | 任务项第二行文字 |
| 焦点高亮 | 当前最前台窗口的强调色背景、边框和底部高亮条 |
| 焦点指示条 | 焦点任务项底部的强调色短横条 |
| 悬停高亮 | 鼠标移到任务项上时出现的强调色背景、边框、阴影和放大效果 |
| 最小化标记 | 任务项右侧圆圈中的减号，表示窗口已最小化 |
| 工具区 | 任务栏最右侧的按钮区域 |
| 刷新按钮 | 工具区中的圆形箭头按钮 |
| 设置按钮 | 工具区中的齿轮按钮 |
| 权限提示区 | 未获得辅助功能权限时显示的提示内容 |
| 打开设置按钮 | 权限提示区内用于请求辅助功能权限的按钮 |

## 任务项菜单

| 固定名称 | 指代内容 |
|---|---|
| 任务项菜单 | 右键或长按任务项后出现的操作菜单 |
| 显示全部窗口 | “显示该 App 的所有窗口”菜单项 |
| 关闭窗口 | “关闭此窗口”菜单项 |

## 设置窗口

| 固定名称 | 指代内容 |
|---|---|
| 设置窗口 | 点击设置按钮后弹出的独立窗口 |
| 主题选择器 | 浅色、深色两个选项组成的分段控件 |
| 浅色模式 | 使用浅色外观显示 TaskDock |
| 深色模式 | 使用深色外观显示 TaskDock |
| 隐藏 App 开关 | “显示隐藏 App 的窗口”复选框 |
| 黑名单区 | 设置窗口中管理不显示 App 的区域 |
| 黑名单说明 | 黑名单区标题下方的说明文字 |
| 黑名单列表 | 可加入或移出黑名单的 App 列表 |
| 黑名单勾选框 | 每个 App 左侧的复选框 |

## 操作名称

| 固定名称 | 操作含义 |
|---|---|
| 切换窗口 | 左键单击任务项，激活对应窗口 |
| 悬停任务项 | 鼠标移动到任务项上但不点击 |
| 打开任务项菜单 | 右键单击或长按任务项 |
| 显示 App 全部窗口 | 在任务项菜单中选择“显示该 App 的所有窗口” |
| 关闭任务窗口 | 在任务项菜单中选择“关闭此窗口” |
| 刷新窗口列表 | 点击刷新按钮 |
| 打开设置窗口 | 点击设置按钮 |
| 切换主题 | 在主题选择器中选择浅色或深色 |
| 显示隐藏 App | 打开隐藏 App 开关 |
| 隐藏隐藏 App | 关闭隐藏 App 开关 |
| 加入黑名单 | 勾选黑名单列表中的 App |
| 移出黑名单 | 取消勾选黑名单列表中的 App |
| 恢复最小化窗口 | 点击带最小化标记的任务项 |

## 状态名称

| 固定名称 | 状态含义 |
|---|---|
| 当前焦点窗口 | 当前真正位于系统最前台的窗口 |
| 普通窗口 | 已显示、未获得焦点、未最小化的窗口 |
| 最小化窗口 | 当前处于最小化状态的窗口 |
| 隐藏 App 窗口 | 所属 App 被 macOS 隐藏的窗口 |
| 黑名单 App | 已设置为不在 TaskDock 显示的 App |
| 无标题窗口 | 没有窗口标题、因此回退显示应用名称的窗口 |

## 推荐说法示例

- “把任务项的悬停高亮再深一点。”
- “焦点指示条改成 4 像素高。”
- “隐藏 App 开关默认打开。”
- “把微信加入黑名单。”
- “任务项压缩后只显示应用图标和窗口标题。”
- “设置窗口宽一点，黑名单列表增加搜索框。”
