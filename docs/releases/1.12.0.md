# TaskDock 1.12.0

## 新增

- **窗口自动避让**：最大化、左右半屏窗口在布局稳定后自动收边，为 TaskDock 留出空间。
- 开发者设置新增“所有重叠窗口避让”，开启后，非焦点窗口也能自动避让。
- 支持直接收边或动画过渡，可调整动画时长、布局等待时间及底边出屏阈值。
- 超过出屏阈值的窗口保持原位，任务项临时增强底色，改善白色文字的可读性；遮挡解除后自动恢复。

## 优化与修复

- 优化遮挡场景下任务项的选中、悬停和未选中状态，增强区分度。
- 任务栏玻璃效果统一由通透度滑杆控制，移除“跟随系统”开关。
- 修复关闭收藏栏放大后，鼠标悬停导致收藏文件夹抖动的问题。
- 更新提醒加入可滚动的更新日志，底部操作按钮固定。安装此版本后，后续更新提醒将显示日志。

## 设置保留

- 更新后保留用户已有设置，不再用发布者的外观参数覆盖。
