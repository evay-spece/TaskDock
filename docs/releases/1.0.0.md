TaskDock 1.0.0（Build 10）

本版集中完善任务栏收藏区、最近 App 和窗口任务项的日常交互。

- 收藏 App 和文件夹支持拖入、排序；拖出收藏栏连续停留 0.5 秒后，松开鼠标才移除。拖回时图标接续浮动预览的位置。
- 收藏图标放大时改善点击归属和相邻任务项遮挡；废纸篓、文件夹显示名称提示。
- 最近打开的 App 按运行状态分组，列表中可点击星形按钮收藏或取消收藏。
- 任务栏可将同一 App 的 3 个及以上窗口折叠成一个任务项，点击选择具体窗口；可在设置中关闭。
- 新增任务栏两侧留白、任务项文字大小和降低动画强度设置，并跟随 macOS 的“减少动态效果”。
- 增加 7 天试用期结束后的使用提醒；提醒不阻止继续使用。
