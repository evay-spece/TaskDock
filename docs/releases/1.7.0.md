# TaskDock 1.7.0（Build 116）

任务栏更新了液态玻璃外观和任务项可读性：选中项更醒目，未选中项融入底座；支持浅色、深色和跟随系统。开发者设置中可选择系统玻璃效果或单独调节 TaskDock 通透度。

本次升级会应用新的任务栏布局默认值：50 pt 高度、88 pt 两侧留白、8 pt 任务文字、自适应任务项宽度，以及与主力机当前一致的外观参数。收藏 App、文件夹和历史记录保留。

每次安装新版本，融合模式、右键功能和开发者调试的设置入口会重新隐藏；已启用的功能保持原状态，可在“关于”中按原彩蛋方式重新显示入口。
