# TaskDock 1.9.0（Build 155）

- 设置滑杆改为连续调节，并标记发布默认位置、轻微吸附；任务栏大小和收藏图标放大左右排列，放大滑杆最左侧为关闭。
- 任务项固定为自适应长度；点击立即反馈选中状态，鼠标悬停高亮更清楚、即时显示。
- 开发者调试新增收藏放大时右侧内容整体让位开关，以及最大化、半屏窗口避让延时；收藏放大时任务栏背景跟随延伸。
- 支持将文件拖到收藏栏废纸篓进行可恢复删除；通用新增 Option+D 全部最小化／恢复开关。
- 移除用户反馈页面，关于新增联系邮箱 tee@live.cn；本次升级关闭右键功能，隐藏三个调试设置入口。
- 增加永久试用内测口令支持。
- 发布前采集主力机已调好的外观参数。用户首次打开新版本时应用这组外观参数；收藏、文件夹、历史记录、授权及功能开关保留在本机。同版本后续调整不会被反复覆盖。
- 发布预检会核对外观快照与主力机设置，避免漏带最新参数。
