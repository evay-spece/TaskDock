TaskDock 0.4.0（Build 9）

本版将已在主力机验证的最新任务栏与设置界面正式打包发布，并修正 v0.3.0 安装包误收录旧二进制的问题。

- 最近打开的 App 使用原时钟图标，不显示数量；弹出列表打开时不再默认高亮首项。
- 各模式分别配置主题、透明度和窗口显示；融合模式与矩阵模式标注为实验功能。
- 设置选择项改用较紧凑的下拉菜单，减少设置变更时不必要的窗口刷新。
- 安装包从 Swift 当前实际构建输出取可执行文件，并核对最近 App 入口与收藏文件夹等新版功能。
