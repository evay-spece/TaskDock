# TaskDock 1.6.2（Build 82）

## 更新内容

- 新增 Chrome / Edge 配套扩展和本机通信支持，按文件显示独立下载任务、下载进度及完成后的文件操作。
- 优化下载任务行的文字、布局和完成状态保留体验。
- 改善任务项拖动排序、窗口底边收起与鼠标避让体验。
- 增加“隐藏全部 App”操作，并优化默认布局恢复。
- 完善可选文件操作及第三方菜单管理能力。

## 使用说明

- 适用于 Apple Silicon Mac。
- Chrome / Edge 下载进度需在设置中安装并连接配套扩展。
- 现有辅助功能授权沿用；安装后若系统要求重新授权，请按系统提示操作。
- 使用现有 Apple Development 签名，未办理 Developer ID 与 Apple 公证。
