TaskDock 1.3.0（Build 24）

- 新安装可试用 7 天；菜单栏显示剩余试用天数，支持手动发放内测激活码再延长 7 天。
- 设置页开关改为带说明的卡片布局，设置窗口跟随 macOS 外观；更新应用图标和任务栏玻璃视觉。
- 最大化及普通左右半屏窗口使用「轻抬」动画，为任务栏留出空间，并避免反复调整造成跳动。
- 优化收藏栏、任务项与最近使用 App 的视觉细节；减少后台焦点观察器的重复注册开销。

适用于 Apple Silicon Mac。可从 TaskDock 菜单栏的“检查更新”安装，或下载 `TaskDock-1.3.0-macOS-arm64.zip`。
