# TaskDock 1.5.2（Build 48）

## 更新内容

- 接入离线授权：7 天完整试用，¥59 一次性购买；人工核款、邮件发码，激活后离线使用。购买入口支持支付宝/微信原图收款码、多行激活码粘贴及明确的激活结果提示。
- 收藏增减后立即重排，修复收藏、最近打开 App 与任务项重叠；收藏菜单加入空心五角星，“未运行”改为“已关闭”。
- 任务项支持固定长度与按标题自适应长度，优化透明度、悬停反馈、拖动样式，并增加任务栏顶部高光。
- 最大化、左半屏、右半屏窗口默认动画收起底边；顶部和左右位置不变。普通窗口仅在鼠标靠近屏幕底部且小幅重叠时处理，明显出屏时跳过。
- 补强最小化窗口的保留与恢复，改善窗口子角色改变时任务项丢失的兼容性；单窗口 App 也优先使用系统最小化。
- 右下角“最小化全部窗口”采用原生矩形热区，覆盖至屏幕右边缘和底边。
- 更新备份改为 ZIP 保存，减少旧版 App 副本出现在系统搜索中的情况。

## 使用说明

- 适用于 Apple Silicon Mac。
- 首次使用需按 App 提示开启辅助功能权限。
- 付款申请需要买家主动发送邮件；打开邮件草稿不等于已发送。
- 使用现有 Apple Development 签名，未办理 Developer ID 与 Apple 公证，安装可能被 macOS 拦截。
- DS Player、WhatsApp 的 ⌘M 最小化问题已做兼容性补强，仍待这两款 App 的实际用户回测；原生产签发端联调与干净买家 Mac 首次安装尚未独立验收。
