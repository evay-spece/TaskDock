# TaskDock 0.2.3

## 本次更新

- 新增应用内在线更新：在设置中检查到新版本后，可直接“下载并重启”。
- 更新过程会显示下载、验证、安装和重启状态。
- 安装前验证 GitHub SHA-256、TaskDock Bundle ID、版本、arm64 架构、代码签名及签名团队。
- 更新失败时保留当前版本，并提供 GitHub 发布页作为人工回退入口。
- 设置重新分为“通用、任务栏模式、融合模式、矩阵模式”四个 Tab，相关选项按用途归类。
- 融合模式可跟随 Dock 的基础尺寸变化，融合栏、任务项、图标、文字和功能按钮同步缩放；鼠标悬停产生的临时放大不会干扰布局。
- 自动排除 Finder 快速预览、图片快速查看、输入法等内部临时窗口，减少任务项闪现。
- 新增用户维护的窗口类型屏蔽规则，可从任务项右键菜单屏蔽，并在设置中恢复。

说明：旧版 TaskDock 尚无更新器，需要最后手动安装一次 0.2.3；后续版本即可在应用内更新。
