# TaskDock 1.7.2（Build 137）

任务栏模式的窗口任务项平时无底色与边框；鼠标指向未激活项时显示轻圆角胶囊；悬停判定改为读取实际鼠标位置，兼容非激活任务栏面板，并加快移入反馈，激活项保持更深的胶囊和进度标记。

非选中标题加入轻微字形阴影，便于在不同壁纸上阅读。任务栏模式移除“任务项淡化”设置，非选中项保持清晰；融合模式的透明度设置保留。

开发者调试新增“任务项胶囊底色强度”滑杆，可即时调整激活和悬停任务项的灰白色底层，100% 保留原效果。

自动检查更新时，若新版本的大版本号或次版本号高于当前安装版本，会弹出一次更新提醒。补丁版本仍在设置与菜单栏显示，不会主动弹窗。

设置中不提供深浅色切换。任务栏与任务项固定为当前深色外观，不随 macOS 深浅色切换；大气泡、小气泡、设置页及其他普通窗口跟随系统。原有玻璃通透度设置不变。

同一 App 的多窗口列表也使用标准大气泡，随系统深浅色切换。

授权不可用时，启动或再次打开 TaskDock 会显示购买与激活窗口，避免应用只剩后台进程而没有可见入口。

超过 3 个浏览器下载任务时，展开列表使用统一的大气泡窗口，并采用与“最近打开的 App”相同的透明列表行；保留滚动、文件操作和关闭行为。

下载任务折叠入口改为内容自适应的紧凑按钮；闲置时融入任务栏，悬停或展开时显示轻量圆角底色。

下载折叠入口使用下载箭头图标；全部任务完成时，在图标右上显示绿色对勾。
