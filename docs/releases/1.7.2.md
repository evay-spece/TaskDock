# TaskDock 1.7.2（Build 127）

任务栏模式的窗口任务项平时无底色与边框；鼠标指向未激活项时显示轻圆角胶囊；悬停判定改为读取实际鼠标位置，兼容非激活任务栏面板，并加快移入反馈，激活项保持更深的胶囊和进度标记。

非选中标题加入轻微字形阴影，便于在不同壁纸上阅读；设置中的“非选中项透明度”相应调整为“非选中项淡化强度”。

自动检查更新时，若新版本的大版本号或次版本号高于当前安装版本，会弹出一次更新提醒。补丁版本仍在设置与菜单栏显示，不会主动弹窗。

移除设置中的浅色/深色/跟随系统切换。TaskDock 外观固定为当前深色样式，任务栏与任务项不随 macOS 浅色/深色切换；原有玻璃通透度设置不变。

超过 3 个浏览器下载任务时，展开列表使用统一的大气泡窗口；保留滚动、文件操作和关闭行为。
