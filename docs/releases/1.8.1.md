# TaskDock 1.8.1（Build 143）

- 优化任务栏和任务项的固定深色外观，改善非选中项文字对比度，并加快悬停胶囊反馈。大气泡、小气泡和设置窗口继续跟随 macOS 外观。
- 开发者调试新增任务项胶囊底色强度、任务栏黑色底色透明度。黑色底色与原生玻璃透明度分别调整。
- 设置页标题固定在顶部；移除菜单栏中的“显示模式”子菜单。任务栏模式移除作用较弱的“非选中项淡化强度”设置，融合模式的透明度设置保留。
- 浏览器下载超过 3 项时折叠为紧凑入口，展开后使用统一的大气泡列表。完成状态使用下载图标加绿色对勾。
- 授权不可用时显示购买与激活窗口，避免只剩后台进程而没有可见入口。
- 自动检查更新时，遇到较新的大版本或次版本会弹窗提醒一次；补丁版本仍可在设置中手动检查。

本版未改变最大化窗口的 Taskbar 避让方式。
