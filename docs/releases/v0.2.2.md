# TaskDock 0.2.2

## 本次更新

- 新增 Dock 融合模式：Finder 窗口位于系统 Dock 左侧，其他多窗口 App 位于右侧。
- 融合栏会跟随系统 Dock 的稳定尺寸变化；Dock 临时悬停放大时不再反复跳动。
- 新增收藏 App、任务栏对齐选项和菜单栏控制；保留“一键最小化全部窗口”。
- 优化任务栏、窗口矩阵和融合模式的尺寸、透明度、高亮及拖动动画。
- 自动过滤保存、选色等临时弹窗，以及应用内部工具窗口。
- 修复黑名单 App 无法在设置中恢复的问题。
- 修复 Finder 最小化后任务项消失的问题。
- 修复通过 Alt-Tab 切换窗口后焦点高亮不同步的问题。
- 修复 Edge 多窗口位置和尺寸相同时识别错误，提升点击切换、置前和高亮稳定性。
- 最大化或左右分屏窗口会为底部 TaskDock 保留适量空间，避免内容被遮挡。

## 安装

下载 `TaskDock-0.2.2-macOS-arm64.zip`，解压后将 `TaskDock.app` 移入“应用程序”文件夹。首次运行请在“系统设置 → 隐私与安全性 → 辅助功能”中允许 TaskDock。
