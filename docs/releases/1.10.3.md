# TaskDock 1.10.3（Build 169）

- “设置 → 通用”新增开机启动开关，使用 macOS 原生登录项；状态随系统同步，需要系统允许时显示提示。开机启动选择由用户自行管理，不随升级默认参数覆盖。
- 修复“最近运行过程序”的小气泡在光标移开后偶尔残留的问题；大小气泡统一使用真实鼠标位置检测。
- 设置中的滑杆统一为系统原生样式，采用 macOS 27 SDK 构建；保留连续调节、实时预览与保存、默认值标记和吸附。
- 同步主力机最新的 28 项外观及悬停参数，升级后首次启动应用；保留个人收藏、文件夹、历史记录和授权。
- 更新后，融合模式、右键功能、开发者调试的隐藏设置入口恢复关闭。

适用于 Apple Silicon Mac。开机启动开关需要 macOS 13 或更高版本；控件外观随系统版本适配。
