# TaskDock 1.10.2（Build 165）

- 最近程序新增悬停方式：显示“最近运行过程序”的小气泡，或直接展开程序列表大气泡，可在“设置 → 任务栏 → 最近程序”选择。
- 关闭收藏放大效果后，仍可悬停查看程序名称小气泡。
- 优化收藏栏放大时右侧让位：最近程序与任务项保持稳定，减少光标移动时的抖动。
- 下载进度改用实色绿色，提升进度条辨识度。
- 提高 Option + D 全部收起／恢复的可靠性。
- 备忘录任务项显示所选备忘录标题，去掉备忘录数量；清理 Edge 标题中的内存占用提示。
- Finder 扩展中的“剪切”和“粘贴并移动”相邻排列。
- 同步主力机当前外观及悬停设置，升级后首次启动应用；保留个人收藏、文件夹、历史记录和授权。每次更新后，融合模式、右键功能、开发者调试的隐藏入口恢复关闭。

适用于 Apple Silicon Mac。
