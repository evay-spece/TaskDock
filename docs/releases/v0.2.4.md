# TaskDock 0.2.4

## 本次更新

- 任务栏模式新增适应长度／左右铺满、收藏图标悬停放大开关，以及手动添加和拖动排序收藏项。
- 优化任务项按 App 整组拖动的跟手性与让位动画；收藏排序采用一致的拖动交互。
- 通用设置新增 App 名称显示、非选中项透明度和高亮颜色选择，并调整任务项焦点与悬停视觉效果。
- 融合模式新增左右侧 App 分配、显示所需的最少窗口数、底栏开关与实验性 Dock 叠加选项。
- 新增隐藏系统 Dock 的可选设置；TaskDock 退出时恢复原有 Dock 状态。
- 日历收藏图标显示当天日期，并调整融合模式与任务栏模式的布局和动画。

## 安装与更新

已安装 0.2.3 或更新版本的用户，可在 TaskDock 设置中检查更新并安装；也可从此 Release 下载 macOS Apple Silicon 安装包。
