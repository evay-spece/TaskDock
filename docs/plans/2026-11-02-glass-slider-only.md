# 任务栏玻璃统一由滑杆控制

来源：主力机备忘录《taskdock修改》，10月30日内容及内嵌截图，于11月2日通过备忘录原生界面读取。

要求：删除“液态玻璃效果跟随系统”开关；磨砂程度由现有通透度滑杆实现。

实现：移除设置开关及滑杆对开关的依赖；支持的系统始终以已保存通透度覆盖进程内玻璃参数。旧开关键保留但不参与行为判断，避免旧版保存值恢复系统跟随。已有滑杆值及其他用户设置保持不变。未支持系统保留兼容材质。

验证：glass-preference-isolation-selftest 验证旧开关 true/false 都不再跟随系统，滑杆变化仍更新玻璃，没有重复材质层或窗口激活。

仅本地开发变更，未加入 WorkBuddy 的 1.11.0 Build174 发布候选。

结果：Release 构建通过，SDK27/minOS12；回归测试通过；本地 Build178 已签名、安装并通过原生界面确认启动。Build177 保留在 dist/retired/TaskDock-build177-before-slider-only.app。未进行发布。
