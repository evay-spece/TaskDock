# 1.9.0 补充修改

来源：macOS 备忘录《taskdock修改》，直接读取文字及两张内嵌参考图。

- 所有滑杆改连续调节；当前值作为发布默认值，标记默认位置并轻微吸附。大小与图标放大左右排列；放大最左关闭。
- 删除任务项与动画设置，固定自适应。
- 删除用户反馈入口及相关代码；关于增加 tee@live.cn。
- 右键功能关闭；三个隐藏设置入口每个新 Build 重置为隐藏。
- 悬停高亮稍增强；点击与悬停即时反馈。
- 激活码暗号 whosyourdaddy 可获得永久试用。
- 收藏放大时延长任务栏背景覆盖 Finder。
- 开发者增加收藏放大时右侧内容整体让位开关；开启后最近 App 保留显示。
- 开发者增加最大化、半屏窗口避让延时。
- 支持文件拖至废纸篓进行可恢复删除。
- 通用增加 Option+D 全部最小化开关。
- 版本 1.9.0，完成后发布 GitHub；发布后在提醒事项创建当天 07:00 提醒，标题浓缩为 20 字。

## 已验证

- Release arm64 编译、签名、ZIP 解包与资源检查。
- 外观迁移只应用一次，保留个人收藏与授权数据；主力机收藏 App、文件夹摘要更新前后一致。
- 连续滑杆可保存 1.53 倍、0.137 秒；最左 1.0 倍关闭放大，恢复 1.5 倍重新开启。
- 设置页隐藏三个入口并移除反馈；关于邮箱和通用快捷键开关可见；开发者新增控件可见并可保存。
- 永久试用：过期后兑换、重启、时钟推进 50 年仍可用，未写入购买令牌。
- 废纸篓：仅使用测试文件验证回收与恢复，符号链接目标保持不动；测试文件全部清理。
- 收藏放大几何测试覆盖所有图标的背景边界及右侧让位空间。

实际跨 App 文件拖放手势、不同软件窗口动画及悬停视觉尚未逐一人工验收。
