# 最近程序悬停方式

- 设置 → 任务栏 → 最近程序，增加悬停方式选择；默认“名称小气泡”。
- 名称小气泡显示“最近运行过程序”，复用标准小气泡材质、字号与图标间距。点击时钟仍打开大气泡。
- 程序列表大气泡在悬停时直接展开；光标移入列表继续操作，离开后延迟 250ms 收起，避免跨越图标与列表间空隙时闪退。
- 两种气泡互斥；切换方式、离开界面时清理延迟关闭任务。
