# 开机启动开关

- 设置 → 通用顶部增加“启动 / 开机启动”。macOS 13 及以上使用 SMAppService.mainApp，macOS 12 显示版本要求并禁用此开关。
- 每次打开设置、应用重新激活时回读系统状态；注册/取消失败时恢复实际状态并显示原因。等待系统允许时显示说明和系统登录项入口。
- 不写入发布外观默认值，不随升级覆盖用户开机启动选择。
- 自测覆盖注册、重复注册、取消失败的状态回读、审批状态、系统外部更改后的刷新。
- Release 编译、签名、ZIP 完整性检查完成；Build 166 已安装于主力机。
- 实机操作：初始关闭 → 开启并读取系统 enabled → 退出/重新打开 TaskDock 后仍开启 → 关闭后读取系统 disabled。测试结束恢复关闭。
- 未注销账户或重启整机验证登录后自动启动；未发布 GitHub。
