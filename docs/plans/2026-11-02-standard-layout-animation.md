# 标准布局收边动画开关

在开发者的窗口避让设置内新增“收边动画过渡”。默认关闭，保持直接收边；开启时显示动画时长滑杆，沿用原先保存的动画时长（默认0.24秒，范围0.08～0.6秒）。两种模式使用相同的稳定等待和最大化／半屏识别，目标仍为原有底边位置。

动画按单调时钟进行插值，每个布局操作仅发起一次。动画期间暂停窗口枚举与再次避让；用户拖动、窗口被其他操作改变、应用拒绝尺寸写入、关闭避让或清理预留时，停止后续动画帧。

验证：标准布局策略及原有动画几何回归测试通过；具体应用的动画顺滑程度仍需用户实际使用确认。
