# 最近程序小气泡关闭修复

- 最近程序按钮原先只用 SwiftUI onHover；非激活任务栏面板可能漏掉鼠标离开事件，使名称气泡停留。
- 复用已有 TaskbarPointerHoverTracker：原生 tracking area 配合每 40ms 读取真实鼠标位置，面板隐藏/视图拆除时清理状态。
- 收藏放大遮挡最近程序时停用该按钮的悬停追踪，避免穿透遮挡误触发。
- 大气泡列表也复用相同追踪器，保留跨越图标与列表间隙的 250ms 关闭宽限。
- Build 167 Release 编译、签名及 ZIP 完整性检查完成，已安装主力机；Build 166 已备份。
