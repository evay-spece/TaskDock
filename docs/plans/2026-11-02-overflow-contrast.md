# 超过出屏阈值时临时增强任务栏底色

所有重叠窗口避让开启时，存在与任务栏相交且底边超过用户出屏阈值的普通窗口，则通过内存ObservableObject将任务栏黑色底色透明度暂设70%（黑色不透明度30%）。不写入UserDefaults；条件解除或关闭避让后恢复实时读取的用户设置。多个窗口任意一个符合则维持，不依赖焦点。隐藏、最小化、原生全屏排除。

回归测试覆盖超过48pt、提高阈值解除、非重叠窗口排除。原有几何回归测试通过。

Release构建和签名通过，本地Build182已安装并通过原生界面确认启动。仅状态变化才发布外观更新，避免每个轮询周期刷新视图。临时底色实机观感待用户确认；未发布。
