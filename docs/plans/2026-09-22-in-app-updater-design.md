# TaskDock 应用内更新设计

TaskDock 继续使用 GitHub Release 作为更新源，不引入额外更新框架。设置页读取最新 Release，并只接受名称为 `TaskDock-VERSION-macOS-arm64.zip` 的版本附件。发现新版本后，用户点击“下载并重启”，应用依次显示下载、验证、安装和重启状态。

安装前必须同时通过 GitHub 附件 SHA-256、Bundle ID、版本号、arm64 架构、代码签名和签名团队验证。验证失败时删除临时文件并保留当前版本，同时提供 GitHub 发布页作为人工回退入口。

验证通过后启动独立安装进程。安装进程等待当前 TaskDock 退出，将旧 App 移到同目录的唯一备份路径，再将新 App 原子移动到原位置并启动。启动命令失败时恢复旧 App。更新过程只修改当前 `TaskDock.app` 和本次更新专用临时目录。

旧版本不包含更新器，因此用户需要最后手动安装一次包含该功能的版本；此后的版本可直接在设置中完成更新。
