# TaskDock Dock 融合模式设计

## 目标

- 在现有“任务栏”和“窗口矩阵”之外增加第三种“Dock 融合”模式。
- TaskDock 紧接原生 Dock 的右侧，底边和基础高度保持一致，看起来像 Dock 的延伸。
- 融合模式不显示收藏区；Finder 窗口单独显示在原生 Dock 左侧，其他窗口和功能键显示在右侧。
- 保留收藏图标放大、窗口切换、最小化、设置、隐藏和退出功能。

## 布局与视觉

- 通过辅助功能接口读取原生 Dock 的列表边界，不写死 Dock 的宽度和位置。
- 右侧空间足够时优先放在右侧；空间不足时自动放到左侧。
- 左右使用两个独立面板，不用透明大窗口覆盖原生 Dock 的点击区域。
- 使用系统动态材质，不额外叠加固定灰色，让颜色随系统深浅外观和桌面背景变化。
- 放大图标所需的透明空间不计入窗口避让高度。

## 容错

- 原生 Dock 自动隐藏时仍使用其辅助功能列表的宽度和基础高度定位。
- Dock 完全隐藏、暂时不暴露辅助功能边界时，根据 Dock 图标尺寸、固定项目、分隔项和最小化窗口估算边界；Dock 出现后立即切换到真实边界。
- Dock 重启或辅助功能数据短暂不可用时，TaskDock 暂时回落到屏幕右下角，并在后续刷新时自动重新吸附。
- 原生 Dock 不在屏幕底部时暂时使用回落位置，避免错误覆盖侧边 Dock。
