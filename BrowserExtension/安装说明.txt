TaskDock 下载进度扩展 0.3.1（Chrome / Edge 共用，本地加载版）

配套：TaskDock 1.5.2 Build73 或更新版本，Apple Silicon Mac。

安装与更新
1. 在 TaskDock「设置 → 通用 → 浏览器下载进度」点击「连接 Chrome」或「连接 Edge」。这只启用所选浏览器的本机通信，不需要管理员密码。
2. 点击「打开扩展文件夹」。Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 打开「开发者模式」，选择「加载已解压的扩展」，选择 BrowserExtension 文件夹（包含 manifest.json）。
4. 若已安装0.1.0且加载目录在 TaskDock.app 内，只需在对应扩展卡片上点击「重新加载」，确认版本变为0.3.1。若从其他目录加载，需改为新版目录。
5. 打开扩展弹窗，点击「检查连接」。然后开始下载。

独立下载任务项
- 每个文件独占一个任务项，标题显示文件名，项目中显示此文件的下载进度。浏览器窗口任务项不再附加汇总下载进度。
- 同名文件、不同浏览器或配置档的下载也分别显示，不合并成一项。
- 固定/自适应宽度沿用 TaskDock 设置；文件名过长时截断显示，可悬停查看完整文件名。
- 点击下载项会打开对应浏览器的内置下载列表，不直接打开文件。
- 暂停保留该项并显示“暂停”；完成后保留30分钟，显示“打开文件”“打开文件夹”，取消或失败后移除。
- 总大小未知时显示正在下载，不编造百分比。
- 每个浏览器配置档最多同步128个下载。隐身模式不采集；第三方下载器接管的下载及网页内业务进度不支持。
- 正常下载约每秒同步，全部暂停时每5秒同步；TaskDock定时刷新后显示。断线残留最多15秒过期。

隐私与权限
扩展使用 downloads、nativeMessaging、storage、alarms 权限，权限与0.1.0相同。
仅在本机传输文件名（去除目录的basename）、匿名配置档ID、浏览器类型、下载ID、字节数及暂停状态。文件名用于你要求的任务项标题；仅为已完成文件附带本地保存路径用于主动打开；不传输下载网址、请求头或文件内容，不读取网页正文，也不上传到网络。
浏览器可能将 downloads 权限描述为管理下载，但实际代码只查询状态，不发起、删除或打开任何下载。
本机快照文件仅当前用户可读，已完成文件记录仅显示30分钟；进行中的旧数据在断线后清理，异常退出按15秒有效期忽略。

卸载
在浏览器扩展管理页移除此扩展；在TaskDock设置中点击对应浏览器的“断开连接”。不删除浏览器下载记录。

尚未在 Chrome Web Store / Edge Add-ons 上架。商店发布需登记商店ID后重新验证。

0.3.1：已完成的下载在任务栏保留30分钟，可点“打开文件”“打开文件夹”，右键可移除任务项（不会删除文件）。仅已完成文件的本地绝对路径传给本机TaskDock用于上述操作；不发送网址或文件内容。旧下载历史不会导入。取消、失败或文件已删除时移除。
